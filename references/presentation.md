# 演出与呈现（话语层）

VN 的"好看"不是美术质量决定的，是**演出节奏**决定的。同一批素材，排得好是电影，排得差是 PPT。

## 一、立绘

### 差分数量底线

| 场合 | 需要 |
|---|---|
| 日常对话 | 每种情绪一档（通常 3–5 档） |
| 情绪转折 | 必须有"中途换脸"，不能一场一张 |
| 特写场景 | 半身/胸像一档 |

### 站位

- 单人：居中偏左或偏右，**不要死正中**（正中像证件照）
- 双人：左 1/3、右 1/3，中间留空给对话
- 三人以上：中间的略靠后，避免并列

### 说话方高亮

最省力也最有效的做法：**说话方 100% 亮度，非说话方压到 75%**。不需要额外素材，一个 `matrixcolor` 就行。

### 立绘贴底

一律 `yalign 1.0`，并且**把接地阴影烘焙进 PNG**（椭圆模糊，alpha 约 110）。不烘焙的立绘一定看起来像浮在半空——这是新手最常犯的错。

### 入场与呼吸

- 入场：淡入 + 上浮 20px，0.6–0.8 秒
- 待机：呼吸幅度 **≤ 5px，周期 4–5 秒**。幅度一大就变成"人偶在发抖"

## 二、背景与转场

| 意图 | 转场 |
|---|---|
| 同一场景内情绪变化 | `dissolve 0.3–0.5` |
| 时间跳跃（几小时/几天） | `fade`（先黑后亮，1.5–2s） |
| 地点切换（同一天） | `dissolve 0.8` |
| 冲击、闪回、打断 | 白闪或黑闪，0.1s |
| 视角从黑到亮（醒来） | 黑屏停 0.3–0.5s + 慢 fade |

**规矩**：一部长篇的转场要能"读"出时间感。全都 dissolve，玩家就分不清过了五分钟还是三天。

## 三、CG（事件图）

### 什么时候插

只在**情绪峰值**：告白、决裂、揭示、结局。一场戏最多一张。

### 什么时候不插

- 普通对话（用立绘就够）
- 玩家已经能想象出来的画面（描述得越细，越不需要画）
- 连续两个情绪高点之间（会互相抵消）

### CG 的两种用法

1. **强调**：把关键瞬间放大成一张图
2. **留白**：故意不给 CG，只用立绘+背景+一句话——有时"看不见"比"看见"更重

### 极简的合法性（Narcissu）

全程无立绘、无分支、一本道，20 年后仍被传颂——证明**缺席本身可以是叙事工具，而不是预算妥协**：

- 女主始终没有脸：玩家拼不出濑津美的样子，"不可知"就是这个人物的设计（呼应"留白比看见更重"）
- 语音做成**可选项**（作者明说"是为了与无语音版对比而准备的"）——把"要不要声音"交给玩家，本身就是一次主题选择
- 解锁式后日谈克制收尾，不强行戏剧化

用极简的前提：文本强度必须独自扛起全部情绪——没有美术兜底，每句话都是特写。

## 四、声音

### BGM

- 一律 `fadein / fadeout`，0.5–1.5 秒
- 全剧只留 1–2 处**硬切**（用来砸情绪），多了就失效
- **无声也是配乐**：高潮前一秒全部静音，比加一段弦乐更狠

### 音效

三类必须有：
- **环境底噪**：雨、风、教室人声、蝉——让场景"有空气"
- **动作音**：开门、杯子放下、脚步、布料摩擦
- **UI 音**：点击。**不要做悬停音**

### 语音

- 挂了语音的台词 = **文字钉死**，改一个字就音画不同步
- 主角通常不配音（留给玩家自己读），配角可有可无
- 语音文件命名跟台词一一对应，脚本里紧贴台词上一行

### 主题歌是叙事装置，不是装饰（交响乐之雨）

- OP 歌词提前说出结局：第一遍听是氛围，通关后重听，每句歌词反转含义——**歌本身就是剧透，只是玩家当时不知道**
- 每个角色配专属曲：角色歌是"声音区分法"的听觉版，结局歌随路线而变，音乐本身成为玩家重玩的期待
- 做法：立项时就定主题歌的歌词立意（它与 TRUE END 同源），角色曲在角色卡定型后写

## 五、UI

| 元素 | 建议值 |
|---|---|
| 对话框不透明度 | 0.5–0.7（太实抢戏，太透看不清） |
| 对话框位置 | 底部，左右各留 6% 边距，不要贴边 |
| 边框 | 1px，白 0.14 不透明度 |
| 名牌 | 暖色/主色块，文字用深色，压在框上沿 |
| 字号 | 1080p 下 30–34px，行距 1.5–1.6 |
| 快速菜单 | 能关就关。悬浮对话框下方那一排按钮会毁气氛 |

## 六、玩家便利功能（务必全开）

| 功能 | Ren'Py 默认 | 说明 |
|---|---|---|
| 存档任意位置 | 有 | 别做成只能在章节间存 |
| 回溯（rollback） | 有 | 选错了能退回 |
| 历史记录（backlog） | 有 | 至少保留最近 100 句 |
| 跳过 | 有 | 默认只跳"已读"文字（`preferences.skip_unseen = False`） |
| 自动播放 | 有 | 选项处必须暂停 |
| 文字速度 | 有 | 必须允许调到"瞬间" |

**这些全部不要自己实现**，改样式和默认值就够了。

## 七、一句总结

> 读者记住的从来不是"哪张图好看"，而是**某个瞬间停了一下**。
> 演出的全部功夫，就是决定在哪儿停。
