# 文本与节奏

## 一、单句长度

| 字数（中文） | 判断 |
|---|---|
| ≤ 20 | 短促有力，适合对撞、打断、冷场 |
| 21–45 | 正常叙述，最舒服的区间 |
| 46–70 | 偏长，除非是独白的高潮，否则拆 |
| > 70 | 一屏塞满，读者会跳字 |

拆句的三种方式：
1. **按呼吸拆**：说完一件事停一下 → 下一句说下一件事
2. **按反应拆**：台词之后插一个动作或环境描写当"停顿"
3. **按留白拆**：干脆不说完整，让玩家自己补

## 二、四种句子轮换

一部戏要读着不困，靠的是这四种句子的交替：

- **对答句**：短、直、有攻击性
- **描写句**：环境、光线、声音——用来给节奏踩刹车
- **动作句**：抬手、别过头、脚步停住——比形容词有效十倍
- **独白句**：主角的内心，用来做戏剧反讽（玩家知道，角色不知道）

规则：连着三句同一类，就该换。

## 三、台词的三条硬约束

1. **不要解释设定。** 设定藏在动作和抱怨里，不藏在说明里。
   - 差：`"这栋房子是我父亲留下的，所以我很珍惜。"`
   - 好：`"楼下那扇门别乱开。那是我爸的。"`
2. **允许不礼貌。** 真人说话会打断、会答非所问、会沉默。全部写成完整句的对话是剧本腔。
3. **一句台词只做一件事。** 又要交代信息又要表达情绪又要推进关系，观众一件都记不住。

## 四、声音区分法

让每个角色"听起来不一样"，靠这四件事，不用靠口癖堆砌：

| 手段 | 说明 |
|---|---|
| 句长 | 有人只说短句，有人一开口就是三行 |
| 主语 | 有人永远说「我」，有人习惯说「你」 |
| 停顿时机 | 有人抢话，有人先沉默半拍 |
| 专业词 | 每个人有一个只属于他的说法（称呼、比喻来源） |

测试方法：把角色名盖住，如果能猜出是谁在说话，就成立了。

## 五、内心独白的使用配额

- **开场**：多用，帮玩家建立视角
- **对话中**：一句对话最多配一句独白，且不要复述对方的话
- **情绪高点**：反而要减少，让画面和台词自己说话

独白黄金用法是**戏剧反讽**：玩家知道主角在骗自己，而场上其他角色不知道。这种张力，比任何说明都好用。

## 六、节奏的宏观结构

一场戏（约 3–5 分钟）的标准曲线：

```
入场（低）→ 摩擦（升）→ 一个停顿 → 反转或揭示（最高）→ 余韵（降）
```

**余韵千万别省**：高潮之后立刻切场景，等于把情绪剪断。留一句安静的旁白、一个空镜、或一句不相干的话。

## 七、主题句的螺旋（樱之诗）

一句主题台词，全剧出现 3–5 次，**每次含义加深一层**：

| 出现时机 | 含义层 |
|---|---|
| 序章 | 字面意思（人物自己还没懂） |
| 中段 | 反讽（同一句话在相反处境里说出） |
| 终章 | 救赎（这句话成为答案） |

规则：全剧只留**一句**；每次出现场景必须真的变了；终章那次要让前面所有出现处在玩家脑内同时回响。多了就不是主题句，是复读机。

配套手段：章节标题引用一条贯穿的文本（维特根斯坦、圣经、诗——樱之诗用艺术论），让"读章节名"也参与叙事。

## 八、标点纪律

- 中文台词内引号统一用全角「」和『』，半角 `"` 只作代码里的边界符
- 省略号用 `……`（六点），不要 `...`
- 破折号用 `——`，一句话里最多一个
- 感叹号在一场戏里不超过两次，多了等于没有
