# 选项与分支设计

## 一、宏观结构：共通线 → 分歧 → 个人线

多角色作品的骨架，先画这个再谈任何细节分支：

```
共通线：日常篇（认识所有角色）→ 事件篇（关键事件）→ 分歧点
个人线：深入篇（背景揭露）→ 冲突篇（矛盾爆发）→ 解决篇 → 结局
```

- **共通线要有"选择感"**：虽然是所有人共享的剧本，选项和 flag 要让玩家觉得"我在塑造关系"，而不是在看公共电影
- **个人线要有"专属感"**：进入个人线后，其他角色退到背景，flag 决定的专属台词要出现
- **分歧点只有一个大决策**（或一组连续小决策），放在共通线末尾；之前的小选项只积累变量（见折回结构），不改变走谁的路
- **第三种模型：收敛结构（世界线收束）**——宿命、时间循环题材的解法（命运石之门）：所有小分支都汇入同一批"必须发生的结果"，玩家的选择改变的是*到达收束点的方式与心境*，只有关键分歧点真正跳线。更狠的一步是把结构限制写进世界观：读档、多周目、分支汇合不再是冰冷的系统，而是剧情本身——"世界在阻止你"。普通的 VN 藏起分支结构，一流作品把分支结构做成主题
- **第四种模型：出题/解答二段式**（寒蝉）——先出题后解答：出题篇只给现象不给真相，同一时段循环重演、每次微调；玩家的推理参与是设计的一部分，解答篇的价值由玩家自己折腾过的错误理论兑换。前提：叙述必须"公平地误导"（禁じ手不许越界——线索都在，只是没人说破）。**公平性可以制度化**（海猫的赤字真相）：红字=作者承诺绝对真实，蓝字=玩家的合法反驳——把"线索都在"变成可验证的规则，玩家才敢投入推理。玩叙述诡计的 VN 必须有一处等价的"红字时刻"
- **玩家视点可作为剧中角色**（Ever17 的 Blick Winkel）：玩家自以为在读故事，其实"阅读行为"本身就是剧情装置——双主角视点选择藏在序章，两条时间线（2017/2034）各走各的，最后在同一"视点"上汇合。慎用：全书只能耍这一次，且必须回收得干干净净
- 短篇 / 单线多结局可以跳过这套，直接用下面的折回

## 二、折回结构（foldback）——微观上唯一可持续的分支模型

```
        ┌─ 选项 A ── 一段回应 ─┐
主线 ───┤                      ├─ 汇合 → 一致性台词 → 继续主线
        └─ 选项 B ── 一段回应 ─┘
```

- **分叉只分"怎么回应"，不分"剧情去哪"**
- 回应段长度控制在 2–4 句，够表达立场即可
- 汇合点之后立刻回到同一条时间线

为什么必须这样：分支数按乘法增长。四个选项 × 五个分叉点 = 1024 条路径，没人写得完，也没人玩得完。折回（branch-and-merge）给出"有选择"的感觉，成本只有独立路线的零头；**完整独立路线留给个人线和结局**。

折回的极限形态是《车轮之国》：全书基本一本道，五章推进，所有选项只改变 epilogue 的分配。敢这么做的唯一前提：主线情绪强度足以独自撑满全程，选项退化为"态度记录仪"。

## 三、选项合格性测试（四条全过才算选项）

1. **两条都成立**：没有明显"正确"的那一条
2. **能表达立场**：玩家选的是"我想成为什么样的人"，不是"哪个给分多"
3. **有可见后果**：至少改变一个变量，并在后续被引用一次
4. **不消耗耐心**：玩家读完这段就能判断，不需要查攻略

## 四、选项的六种类型

| 类型 | 用途 | 注意 |
|---|---|---|
| 立场型 | 表达主角性格：嘴硬／服软／沉默 | 最常用，配折回 |
| 信息型 | 决定玩家知道什么（问 A 还是问 B） | 后续要有对应的 flag |
| 时机型 | 现在做 / 等等再说 | 容易做成"假选择"，慎用 |
| 牺牲型 | 二选一，必有损失 | 一部作品最多两处，多了廉价 |
| 双重语义 | 一句话对两个角色各表达一件事（白2 coda 的"坦白"：雪菜听到的是信任，春希回答的是敢不敢直面） | 选项文本的最高段位，潜台词优先的选项版；一部作品两三处即可 |
| 心理型 | 不改剧情，改"主角是什么样的人"（Chaos;Head 的妄想触发：正面=喜剧粉色，负面=恐怖暴力） | 一周目零后果会引发"选项白给"质疑，必须让二周目用同一套选项累计出结局判定才成立 |

### 锁定选项的可见性

条件不满足的选项，**显示置灰**还是**干脆隐藏**，是两个流派：

| 做法 | 效果 | 代价 |
|---|---|---|
| 置灰显示 | 玩家知道"还有别的可能"→ 有二周目动力 | 会剧透"存在更好的选择" |
| 隐藏 | 第一次玩更沉浸 | 玩家不知道自己错过了什么 |

规矩：**全剧统一一种**，混用会让玩家怀疑选项失效了。短篇建议隐藏，主打多周目的建议置灰。

## 五、变量设计

### 三类变量，别混

| 类型 | 例子 | 谁改 |
|---|---|---|
| **数值型** | `trust` 0–11、`edge` 0–14 | 只能通过统一函数改（`aff(n)`），不许散落 `+=` |
| **开关型** | `seen`、`rumored`、`gift_taken` | 事件触发时置 True |
| **代号型** | `gift = "milk" / "cream" / "none"` | 选项时赋值，汇合点读取 |

### 铁律

- **数值改动必须走唯一入口**：一旦有第二个地方直接改，后面所有判定都不可复现
- **变量名定下不改**：改了会弄坏已有存档（Ren'Py 按变量名读旧档）
- **一个变量只承担一个含义**：`trust` 同时表示好感和剧情进度，最后一定会打架
- **好感档位是事件闸门，不是数字游戏**：与 `character-design.md` 第七节联动，每个档位阈值后面要有可解锁的事件

## 六、结局表

先写这张表，再写剧情。

| key | 类型 | 触发条件 | 说明 |
|---|---|---|---|
| `gift_peach` | 彩蛋 | `gift == "peach"` | 后日谈，不改变主线 |
| `refuse` | 坏结局 | `trust <= 0` | 拒收 |
| `empty_stage` | BAD END | `ws_soft == False` | 关键点没回头 |
| `true_end` | TRUE END | 走到最终场 | 必达，别藏太深 |

规则：
- **结局判定只写在一处**（一个 `ending_judge` label），别散落
- **彩蛋结局不改变主线**，只是后日谈分支
- **TRUE END 应该是"走完全程"的默认结果**，而不是隐藏极深的奖励——藏太深会被大多数玩家错过的作品，等于没写
- **例外：勇气型 TRUE END**（白色相簿2）——TE 不靠好感数值堆出来，靠一两个"敢直面"的选项解锁（坦白了才有三人一起解决、放下某人进 TE 的可能）。用这招的前提：其余结局必须各自成立，且勇气选项的双重语义要在通关后回看时成立

## 七、路线锁

三种策略，按作品体量选：

| 策略 | 适合 | 代价 |
|---|---|---|
| 全开放 | 短篇、单线多结局 | 玩家可能跳过关键揭示 |
| 顺序锁 | 多角色线路，需要铺垫 | 二周目成本高 |
| TRUE 线解锁 | 想要"全通关才有完整体验" | 必须保证前几条线各自成立 |

顺序锁的正解是 Fate/stay night：**锁的是信息顺序，不是难度**——前线揭示的事实（Saber 的真身等）成为后线的玩家默认认知，玩家始终以全知视角携带记忆推进；而最后一线（HF）的主题"人类 vs 从者"，靠与前两线的对比才成立。判定标准：锁的理由必须是叙事的（玩家何时知道什么），不是商业的（逼肝）。

TRUE 线解锁的正解是 CLANNAD 的光玉：**路线不互斥，跨线收集**——每条个人线完成时获得一颗光玉（少女的心愿被实现），光玉数量解锁 After Story 的最终拯救。多线并存的道德问题被世界观消化：每条线的幸福都是 TRUE END 的燃料，攻略谁都不浪费。

## 八、流程图与纯文本原型

- 超过 6 个分叉点就必须有流程图，否则作者自己会迷路。Ren'Py 可以在运行时从 AST 自动推导剧情图（遍历 label 与 menu），不必手维护
- **流程图不必只给作者**（YU-NO 的 A.D.M.S.，1996）：把作者视角的分歧图直接做成玩家界面——当前位置、走过的路径、分岔一目了然；它的存档点（宝玉）是**世界内道具**，是 reflector device 的功能，终盘器件失灵传送就失效。系统与剧情咬合到这个程度，便利功能本身就成了叙事
- **上美术之前，先跑纯文本原型**：把全部分支用裸文本（无立绘无 BGM）从头到尾读一遍。节奏问题和死分支在纯文本里暴露得最快，此刻修改成本最低。美术是放大器——放大的先得是对的
