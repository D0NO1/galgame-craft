# 角色设计（结构层）

只管结构，不管腔调——人物的说话方式是作者的辨识度，这里给的是"立得起来"的骨架。

## 一、三层角色设计

每个主要角色（主角＋全部可攻略对象）都要填满这三行，填不出来就还没想清楚：

| 层 | 是什么 | 例：傲娇 |
|---|---|---|
| **表面** | 别人眼中的样子 | 毒舌冷淡，"才不是为了你" |
| **私下** | 只有亲近的人知道 | 偷偷关心、提前把东西准备好 |
| **好感反应** | 随关系变化的言行档位 | Lv0 冷漠 → Lv3 彆扭 → Lv5 撒娇 |

检查法：三行里只要有一行和别的角色重复，这个角色就还没成立。

## 二、反差公式

```
完整角色 = 性格内核 + 关系距离 + 身份 + （一个反差点）
```

- **反差（gap）从"身份带来的渴望 vs 现实"里来**：大小姐渴望普通、偶像想要营业外的真实、不良少女内心柔软——标签是壳，渴望是核
- **一个记忆点就够，最多两个反差**。全身上下全是反差等于没有反差
- 叠加禁忌：两个反差方向冲突的类型不叠（病娇＋病弱太沉重、无口＋电波没法对话、傲娇＋女王S 重叠）
- **把枷锁做成规则**（车轮之国的"义务"）：角色的障碍不靠误会制造，靠一条可执行、有成本、可查询的社会规则（"恋爱禁止的义务"）——冲突从规则里长出来，解决冲突就等于改写规则，剧情张力天然可持续

## 三、类型差异化反应

同一情境，不同角色的反应必须不同——这是"盖住名字能猜出是谁"的结构性保障（配合 `text-and-rhythm.md` 的声音区分法）：

| 情境 | 傲娇 | 冷娇 | 病娇 |
|---|---|---|---|
| 吃醋 | "随便你！"（转身） | "……"（气压变低） | "那个人是谁？"（笑但不达眼底） |
| 被告白 | "才不是！只是……不讨厌你……" | "……喜欢。"（转头，耳朵红） | "终于说出来了。"（抱紧） |

写法：群像戏写完，把每个人的同情境反应排成一列检查——有两列长得像，删掉一列或重写一列。

## 四、口癖与标签纪律

1. **口癖只在关键时刻用**。每句都带口癖，第三幕读者就自动过滤它了
2. **先有背景，再贴标签**。"为什么她是傲娇"答不出来，标签就是纸上人偶
3. **沉默也是台词**。无口、冷娇型的魅力一半在"她没说的那半句"（呼应潜台词优先）

## 五、表情差分标准集

十档标准，按需取用；`special` 是该角色独有的一个表情，留给她的名场面：

```
neutral / smile / laugh / sad / angry /
embarrassed / surprised / crying / love / special
```

最低配置（对应 `presentation.md` 的"至少三档"）：日常至少 `neutral / smile / angry`（或 `embarrassed`），情绪转折那场必须有"中途换脸"。

## 六、CG 指示书要素

每张 CG 配一张指示书，五项全写：

| 项 | 内容 |
|---|---|
| 构图 | 类型（全身/半身/特写）、焦点、视角（仰/平/俯） |
| 角色 | 姿势、表情（用第五节的标准档位名）、动作 |
| 环境 | 场景、时间、天气 |
| 氛围 | 情绪关键词、光线、色调 |
| 关键元素 | 这张图必须被看到的一件东西 |

自检：**氛围一栏写不出来，说明这张 CG 还没到情绪高点**——回去看 `presentation.md` 第三节，要么删掉要么挪。

## 七、好感档位与事件解锁

好感档位不是数字游戏，是**事件闸门**。先写这张表再写日常：

| 档位 | 关系 | 解锁 |
|---|---|---|
| Lv0–1 | 陌生→认识 | 初见、日常对话 |
| Lv2–3 | 朋友→暧昧 | 单独相处、邀请事件 |
| Lv4–5 | 恋人→羁绊 | 告白、个人线入口、TRUE END |

- **档位之间必须有过渡事件**，不许从"朋友"直接跳"告白"（断层是最常见的廉价感来源）
- 档位只增不减可以，但"减分事件"要谨慎——掉好感要给玩家看得见的原因
- 与 `branch-design.md` 的变量表对接：档位就是数值型变量的阈值判定，改动仍走唯一入口
